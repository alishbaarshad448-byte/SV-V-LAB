| State ID | State Name            | Description                                                                                                   | Entry Condition                                                                                                | Exit Condition                                                                          |
| -------- | --------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **S1**   | **IDLE**              | The robot is at the warehouse and waits for a new delivery request.                                           | Robot is switched on with no delivery request, or the robot has reached the warehouse after returning.         | A valid delivery request is received.                                                   |
| **S2**   | **NAVIGATING**        | The robot moves toward the requested destination while monitoring its surroundings and battery level.         | A valid delivery request is received while the robot is in IDLE, or an obstacle has been successfully avoided. | Destination is reached, an obstacle is detected, or the battery becomes critically low. |
| **S3**   | **AVOIDING_OBSTACLE** | The robot temporarily stops normal navigation and performs the necessary actions to avoid an obstacle.        | An obstacle is detected while the robot is navigating.                                                         | The obstacle is successfully avoided.                                                   |
| **S4**   | **DELIVERING**        | The robot performs the package delivery after reaching the destination.                                       | The robot reaches the requested destination while navigating.                                                  | The package is successfully delivered.                                                  |
| **S5**   | **RETURNING**         | The robot travels back to the warehouse after completing delivery or when the battery becomes critically low. | The package is successfully delivered, or the battery becomes critically low during navigation.                | The robot reaches the warehouse.                                                        |
